# feather-progressbar

Version 1.3.0.

> A beautiful, and easy, progress bar API for your scripts. * Download this repo * Copy and paste `feather-progressbar` folder to `resources/feather-progressbar`

Source: https://github.com/FeatherFramework/feather-progressbar

Has NUI (`ui_page`).

## Exports (call as exports['feather-progressbar']:Name)

**client:** `cancelCurrentProgressBar()`, `initiate()`

## Event handlers

**client:** `__cfx_export_progressBars_startUI`
