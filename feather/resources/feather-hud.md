# feather-hud

Version 0.3.2. The player HUD for the Feather Framework

> The official player HUD for the Feather Framework — an always-on Resource Strip showing cash, gold, tokens, and XP/rank. - Always-on Resource Strip: cash, gold, tokens, and an XP/rank bar with a level shield - No interaction, no screen real estate taken up by a panel — legible over any background, never blocks mouse or camera input

Source: https://github.com/FeatherFramework/feather-hud

**Dependencies:** `feather-core`, `feather-economy`

Has NUI (`ui_page`).

## Net events registered

**client:** `Feather:Character:Logout`, `Feather:Character:Revive`, `Feather:Character:Spawned`, `feather-hud:wallets:invalidate`

## Commands (RegisterCommand)

**server:** `/HudEconomyContractSmokeTest`
