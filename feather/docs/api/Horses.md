# Horses

Feather Toolkit can load a horse model and create it through the generic `CreatePed` contract. See [Models and Entities](/api/toolkit/Models-and-Entities) for a current example.

Toolkit owns the spawned handle and automatic cleanup only. Stable ownership, statistics, tack, storage, persistence, and horse gameplay remain the responsibility of a dedicated horse or stable resource.
