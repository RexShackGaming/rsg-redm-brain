# Changelog

All notable changes to rsg-robbery. Newest first.

## 3.1.0

### Added
- Optional rsg-reputation integration (`Config.Reputation`): a successful robbery of another player is reported as the `robbery` action (honor only, no region). Set `Config.Reputation.Enabled = false` to turn it off.

### Documentation
- README and DOCS describe the option.

## 3.0.0

### Documentation
- `DOCS.md`: added a generated technical reference (dependencies, database, configuration, exports, callbacks, events, commands, items, locales) with code examples, read straight from the source.
