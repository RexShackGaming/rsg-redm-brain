# rsg-npcs

Version 3.0.0. rsg-npcs

**Lightweight, distance-based ambient NPC spawner with optional blips, scenarios and proximity audio for RedM.** > Fill towns and custom map areas with static NPCs that only exist when a player is nearby. > Fully client-side and config-driven: no database, no server events, no framework calls.

Source: https://github.com/Rexshack-RedM/rsg-npcs

**Dependencies:** `ox_lib`
