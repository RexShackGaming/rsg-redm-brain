# rsg-loading

Version 3.0.4. RSG RedM Loading Screen

A clean, configurable loading screen for RedM servers running the RSG Framework. Full technical reference: [DOCS.md](DOCS.md) - Custom background image with adjustable dim

Source: https://github.com/Rexshack-RedM/rsg-loading

**Dependencies:** `rsg-core`

## Event handlers

**server:** `playerConnecting`

**client:** `RSGCore:Client:OnPlayerLoaded`
