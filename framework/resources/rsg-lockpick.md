# rsg-lockpick

Version 1.0.0. rsg-lockpick

**Simple lockpicking minigame for RedM (RSG Core).** > A lightweight NUI lockpicking game (pin + cylinder) you can invoke from any script and receive a success/failure callback. - **rsg-core** (framework)

Source: https://github.com/Rexshack-RedM/rsg-lockpick

Has NUI (`ui_page`).

## Event handlers

**client:** `rsg-lockpick:client:openLockpick`
