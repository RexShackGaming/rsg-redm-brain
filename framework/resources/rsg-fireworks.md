# rsg-fireworks

Version 3.0.0. Firework script for RSG Framework

Player-useable fireworks and admin-controlled firework displays for the RSG Framework. **Version:** 3.0.0 **Author:** RexShack

Source: https://github.com/Rexshack-RedM/rsg-fireworks

**Dependencies:** `rsg-core`, `rsg-inventory`, `rsg-gizmo`

## Net events registered

**server:** `rsg-fireworks:server:cancel`, `rsg-fireworks:server:display`, `rsg-fireworks:server:place`

**client:** `rsg-fireworks:client:big_fireworks_players`, `rsg-fireworks:client:display`, `rsg-fireworks:client:display_big_firework`, `rsg-fireworks:client:display_small_firework`, `rsg-fireworks:client:firework_big`, `rsg-fireworks:client:firework_small`, `rsg-fireworks:client:ignite`, `rsg-fireworks:client:small_fireworks_players`

## Usable items

**server:** `firework_big`, `firework_small`
