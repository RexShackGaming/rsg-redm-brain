# rsg-barbers

Version 2.0.7. rsg-barbers

**Fully functional barbershop system for RedM (RSG Core).** > Visit barbershops across the map to customize your hair, beard, and overlays with a smooth in-game camera and clean UI. - **rsg-core** (framework & player data)

Source: https://github.com/Rexshack-RedM/rsg-barbers

**Dependencies:** `rsg-core`, `rsg-menubase`, `ox_lib`

## Net events registered

**client:** `rsg-barber:client:menu`

## Event handlers

**server:** `rsg-barber:server:SaveSkin`

## Server events it triggers in other resources

**client:** `rsg-appearance:server:LoadSkin`, `rsg-barber:server:SaveSkin`
