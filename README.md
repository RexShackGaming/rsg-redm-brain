# RedM Brain

A knowledge base that AI assistants (Claude, ChatGPT, Cursor, etc.) can load before writing RedM / RSG Framework scripts.

**AI entry point:** `CLAUDE.md`. Claude Code reads it automatically when this folder is opened as a project. For other tools, attach or paste it first.

## Keeping it useful
- When you learn something the hard way (a native that needs a specific call order, an item renamed on your server), add it to the relevant file.
- Update `server/environment.md` whenever you add or remove a resource.
- Drop working snippets from finished scripts into `patterns/`.
- Keep files small and focused. AI does best when it can load just the file it needs.
