# Full RedM natives database

Generated by `tools/build_natives.py` from **VORPCORE/RDR3natives** (the same data redm.info/natives shows). Re-generated by `tools/refresh.sh`.

- `INDEX.tsv` — every native: `name<TAB>hash<TAB>namespace`. Grep this first.
- `<NAMESPACE>.md` — one section per native: hash, signature, notes, examples. Grep `^## NAME` with `-A 6`.
- `CFX.md` — CitizenFX (RedM-specific) natives.

Call by name in Lua (`SetBlipSprite(...)`) or by hash: `Citizen.InvokeNative(0x74F74D3207ED525C, blip, sprite, true)`.
Don't read the files whole.
