# vorp_inputs-lua

Version 1.2. An Input tool to use in your scripts for vorp core framework

inputs for vorp framework - `ensure vorp_inputs` - start your server

Source: https://github.com/VORPCORE/vorp_inputs-lua

Has NUI (`ui_page`).

## Exports (call as exports['vorp_inputs-lua']:Name)

**client:** `advancedInput(input)`

## Net events registered

**client:** `vorpinputs:advancedInput`, `vorpinputs:getInput`, `vorpinputs:getInputsWithInputType`

## Commands (RegisterCommand)

**client:** `/closeinput`

## Public (table) functions

**client/models/NUIEventModel.lua:** `NUIEvent:New(t)`
