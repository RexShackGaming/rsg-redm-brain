# vorp_progressbar

Version 1.2.1. A tool to use within your scripts for vorp core framework

> A Client side UI progressbar for VORP Resources * Download this repo * Copy and paste `vorp_progressbar` folder to `resources/vorp_progressbar`

Source: https://github.com/VORPCORE/vorp_progressbar

Has NUI (`ui_page`).

## Exports (call as exports['vorp_progressbar']:Name)

**client:** `CancelAll(cb)`, `CancelNext(cb)`, `initiate()`

## Event handlers

**client:** `__cfx_export_progressBars_startUI`
