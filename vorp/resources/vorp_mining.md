# vorp_mining

Version 1.2. A mining script for vorp core framework

Mining Script for VORP Core - `ensure vorp_mining` in your `server.cfg / resources.cfg` - `ensure vorp_lib` in your `server.cfg / resources.cfg`

Source: https://github.com/VORPCORE/vorp_mining

**Dependencies:** `vorp_lib`

## Net events registered

**server:** `vorp_mining:resetTable`

**client:** `vorp_mining:nopickaxe`, `vorp_mining:pickaxechecked`, `vorp_mining:removePickaxe`, `vorp_mining:togglePickaxe`
