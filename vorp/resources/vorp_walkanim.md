# vorp_walkanim

Version 1.3. A Menu to set walkstyles for vorp core framework

A script that saves players walking style at every server restart - now it uses clothing too - remove or add back the clothing

Source: https://github.com/VORPCORE/vorp_walkanim

## Net events registered

**client:** `vorp_walkanim:Server:setwalk`

## Event handlers

**server:** `vorp:SelectedCharacter`

**client:** `vorp_walkanim:Client:setAnim`
