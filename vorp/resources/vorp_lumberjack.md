# vorp_lumberjack

Version 1.2. A lumberjack script for vorp core framework

Lumberjack Script for VORP Core - ensure vorp_lumberjack` in your `server.cfg` / `resources.cfg` - ensure syn_minigame` in your `server.cfg` / `resources.cfg`

Source: https://github.com/VORPCORE/vorp_lumberjack

**Dependencies:** `syn_minigame`

## Net events registered

**server:** `vorp_lumberjack:resetTable`

**client:** `vorp_lumberjack:axechecked`, `vorp_lumberjack:noaxe`
