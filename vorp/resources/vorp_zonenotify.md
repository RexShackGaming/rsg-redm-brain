# vorp_zonenotify

Version 1.1. A zone notify for vorp core framework

RedM zone notification system for [VORP Core](https://vorpcore.mintlify.app/introduction) 1. Displays a top notification when you enter towns, districts, states, and others. 2. Displays the time within the notification

Source: https://github.com/VORPCORE/vorp_zonenotify

Has NUI (`ui_page`).

## Commands (RegisterCommand)

**client:** `/debug:zoneinfo`, `/zoneinfo`
