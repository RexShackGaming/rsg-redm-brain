# vorp_inventory-v2

Version 1.1. Inventory System for vorp core framework

A complete refactor from original vorp_inventory to be use with vorp_core for RedM - vorp core - oxmysql

Source: https://github.com/VORPCORE/vorp_inventory-v2

Has NUI (`ui_page`).
