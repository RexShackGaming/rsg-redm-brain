# vorp_animations

Version 1.0. A tool to define animations and use them in your scripts with an export

An animation tool for other scripts to utilize. The goal of this script is to make interacting with animations much easier for other developers. This Script allows other script creators to leverage pre-made animations and animation combos with ease of use in mind. * Download this repo * Copy and paste `vorp_animations` folder to `resources/vorp_animations`

Source: https://github.com/VORPCORE/vorp_animations

Has NUI (`ui_page`).

## Exports (call as exports['vorp_animations']:Name)

**client:** `initiate()`

## Commands (RegisterCommand)

**client:** `/endanimation`, `/focus`, `/printcoords`, `/startanimation`, `/testanimation`
