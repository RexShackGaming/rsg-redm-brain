# vorp_outlaws

Version 1.0. A Npc outlaw ambush scrip for vorp core framework

An outlaw ambush script - `ensure vorp_outlaws` in your `resources.cfg` file - configure the script to your likings

Source: https://github.com/VORPCORE/vorp_outlaws

## Net events registered

**server:** `vorp_outlaws:check`, `vorp_outlaws:remove`

**client:** `vorp_outlaws:canstart`
