# vorp_fishing

Version 1.2. A fishing script for vorp core framework

🐟 Lua version of vorp_fishing based on the amazing work of the FRP_Framework team 🐟 - [VORP-Core](https://github.com/VORPCORE/VORP-Core/releases) - [VORP-Inputs](https://github.com/VORPCORE/VORP-Inputs/releases)

Source: https://github.com/VORPCORE/vorp_fishing

**Dependencies:** `vorp_core`, `vorp_inventory`

## Net events registered

**server:** `vorp_fishing:discord`

**client:** `vorp_fishing:UseBait`

## Event handlers

**server:** `vorp_fishing:discord`

**client:** `vorp_fishing:resetFishing`

## Callbacks (VORP Core.Callback.Register)

**client:** `vorp_fishing:checkRodAndBait`
