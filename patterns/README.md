# Patterns

Tested building blocks. Copy and adapt them, and add your own as scripts mature.

| File | What |
|---|---|
| `server-reward-event.lua` | Secure purchase/reward event: validation, distance, cooldown, CanAddItem, RemoveMoney |
| `nui-bridge.lua` | Client NUI open/close, focus handling, callbacks |
| `entity-cleanup.lua` | Model loading with timeout, ped/prop/blip spawn and tracked cleanup |
| `rsg-target.lua` | rsg-target on models/coords, with server-side validation |

Prompt (native) pattern: see `natives/prompts-blips-entities.md`.
